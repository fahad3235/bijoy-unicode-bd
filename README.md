# Bijoy ↔ Unicode Converter — bijoy-unicode-bd

Offline, two-way converter between **Bijoy 2000 (SutonnyMJ)** text and **Unicode Bangla**. Paste Bijoy text copied from a press file, Word document or Photoshop layout and get readable Unicode Bangla — or paste Unicode Bangla and get Bijoy codes back for print work. 100% client-side; your text never leaves the page.

Live: https://fahad3235.github.io/bijoy-unicode-bd/

## Problem

Bangladesh's print industry still runs on Bijoy (SutonnyMJ), a legacy font encoding that stores Bangla as English letters and symbols (`Avwg evsjvq` only *looks* like `আমি বাংলায়` when the SutonnyMJ font is applied). That text cannot be searched, posted, emailed or stored in a database. Converting it by hand is slow and error-prone: in Bijoy the kars ি, ে and ৈ are typed *before* the consonant, ো and ৌ are split around it, and reph is typed *after* it — a converter that only swaps codes leaves kars on the wrong letter.

## Features

- **Two-way live conversion** — Bijoy → Unicode and Unicode → Bijoy, as you type, with a swap button.
- **Full Bijoy 2000 table** — 260-entry mapping (vowels, consonants, ~190 conjuncts, digits, taka sign, dari, curly quotes) from OpenBangla **Poriborton** (MIT), including correct kar reordering, reph, ya/ra/ba/la/ma-phala, split o/ou-kars, and the special গু / শু / হু / হৃ / ন্তু glyphs.
- **Round-trip verify** — converts the result back and reports whether it returns the exact input, with a difference count.
- **Samples** — famous line (`আমি বাংলায় গান গাই`), a paragraph, and a conjunct showcase.
- **.txt file in / out** — open a `.txt` file, convert, download the result (1 MB limit).
- **Bilingual EN / বাংলা UI** with Bengali digits, persisted in `localStorage` along with direction and text.
- **100% offline** — no network requests, no tracking, no server.
- **Responsive** — verified at desktop and 390px mobile widths.

## How it works

- `unicodeToBijoy` is a faithful port of Poriborton's `unicode_to_bijoy` (Rust): a buffered cluster converter that handles front kars, the `ু`-kar variants (`z`/`y`/`–`/`“`…), `ো`/`ৌ` splitting, reph (`©`), ya-phala (`¨`) and ZWNJ.
- `bijoyToUnicode` is an original inverse built on the same table: longest-match tokenisation over the inverted map, then reordering (pre-base kars move after their cluster, split kars rejoin, reph moves before its cluster, phala codes attach to the preceding cluster), plus fallback rules for conjuncts outside the table.
- `য়`, `ড়`, `ঢ়` always come out in their single-letter spellings; decomposed nukta spellings (`য` + nukta etc.) are normalised on input.
- A conjunct the table does not know is written with an explicit hasant instead of being dropped (Poriborton itself drops it).

## Limitations (honest)

- **SutonnyMJ (Bijoy 2000) only.** Other Bijoy fonts (Boishakhi, Bongshi, BornoSoft) use different codes and will come out wrong.
- **English mixed into Bijoy text reads as Bangla glyphs** — convert Bangla passages only. Digits `0–9` become Bengali numerals.
- **A few symbols are shared with punctuation** (`&`, `\`, `|`, `^`): a literal backslash in Bijoy text is read as double-dari `॥`, so it does not survive a round-trip.
- **Explicit hasant `&`** becomes hasant + ZWNJ before a following consonant cluster (that is what stops conjunct formation); at a word end it is a plain hasant.
- Plain-text only: no `.doc` / `.pdf` import, no formatting kept.

## Tech stack

- Vanilla HTML + CSS + JavaScript (no framework, no build step, no dependencies).
- Conversion table generated from OpenBangla Poriborton (`src/bijoy2000.rs`, MIT) by `.scratch/gen.py`; UI strings generated by `.scratch/gen_i18n.py`. Both generators emit pure-ASCII files (non-ASCII as `\uXXXX` escapes) so pushes stay ASCII-safe.

## Run locally

```bash
# any static server, or just open the file:
open index.html
# or
python3 -m http.server 8000
# then visit http://localhost:8000/
```

No install, no env vars, no keys.

## Tests

```bash
node tests/convert.test.js   # 3048 checks: 734 Poriborton pairs + 25 extras,
                             # both directions + round-trips + edge cases
node tests/smoke.js          # 32 headless-Chrome checks (raw CDP):
                             # live conversion, samples, verify, swap, clear,
                             # BN toggle + persistence, 390px, zero network
```

Ground truth: every `assert_eq` pair from Poriborton's `tests/bijoy2000.rs`, its inline `#[cfg(test)]` module in `src/bijoy2000.rs`, and the doc example in `src/lib.rs` — 734 unique pairs, checked Unicode→Bijoy, Bijoy→Unicode, and both round-trips.

## Project structure

```
index.html            app shell (ASCII; Bengali injected by JS)
styles.css            responsive styling, no external assets
js/
  data.js             Bijoy 2000 table (generated, 260 entries)
  convert.js          unicodeToBijoy + bijoyToUnicode engine
  i18n.js             EN/BN UI strings + samples (generated)
  app.js              UI glue, persistence, file in/out
tests/
  convert.test.js     node unit tests
  smoke.js            headless-Chrome smoke test (raw CDP)
  poriborton-pairs.json   generated ground-truth pairs
  extra-pairs.json        generated hand-checked pairs
.scratch/
  gen.py              parses Poriborton Rust sources -> data.js + pairs JSON
  gen_i18n.py         UI strings -> i18n.js
```
