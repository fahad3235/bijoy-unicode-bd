### Documented exceptions (by design, not bugs)

1. **Backslash pair** (`"'/{}();:![]\`): Poriborton asserts U2B passthrough
   only. In Bijoy a backslash *is* the double-dari code, so B2U reads it as
   `॥`. The harness skips B2U + RT-U for this one pair; U2B + RT-B pass.
2. **`&` (explicit hasant)** becomes hasant + ZWNJ before a following
   consonant cluster, plain hasant at a word end — matches Poriborton's own
   ZWNJ test cases (`স্প্‌ল` → `¯c&j` etc.).
3. **Unlisted conjuncts** (e.g. `জ্ম`): Poriborton drops them; this build
   writes an explicit hasant cluster (`R&g`) instead. Deliberate fix,
   documented in README.
4. **`ক্তু`-class clusters**: Poriborton pops the whole single-glyph code
   (`³`) when applying the `‘` (ta+u) shortcut; this build uses the regular
   u-kar code (`³z`) instead so the cluster is not lost.
5. **Latin text in Bijoy input** reads as Bangla glyphs (`Hello` → `ঐবষষড়`)
   — inherent to the encoding; documented, not a bug.

## Repairs during this run

- 3 reverse-direction bug classes found by the corpus and fixed (all in
  `js/convert.js`): `‡`/`‰` are pre-kars like `†`/`ˆ` (not post-kars);
  phala/second-consonant codes are cluster continuations (must not flush a
  pending e-kar or owed i-kar); `&` + following cluster needs ZWNJ.
- 1 forward bug: `output.pop()` removed a whole multi-char token instead
  of one char (`কিন্তু` → `wK‘`); now pops one char, guarded on `—`.
- 2 missing reverse rules added: `|` → `।`, `\` → `॥`; `¨` after lone `র`
  inserts ZWJ (`র‍্যাব`).
- Nukta normalisation added to `unicodeToBijoy` (য/ড/ঢ + nukta → য়/ড়/ঢ়).
- 6 unclassified MAP-value chars found by a coverage audit and given
  fallback rules (`^`, `Ÿ`, `Œ`, `—`, `’`, `‹`).
- 1 test-side fix: `index.html` title used a raw em dash that the
  ASCII-conversion step mangled; now `&mdash;`.
